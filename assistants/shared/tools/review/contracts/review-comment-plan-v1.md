# Review Comment Plan v1

`review-comment-plan/v1` is a provider-neutral logical plan compiled from a
human-editable review draft. It records provider/change identity, source-draft
digest, all inline/general/reply candidates, locations, stable deduplication
keys, selection, validation, and local outcome state.

Selection is not authorization. The plan contains no exact provider payload,
credentials, request headers, or complete remote transcript.
