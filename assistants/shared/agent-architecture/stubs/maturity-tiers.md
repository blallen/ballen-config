# Agent Maturity Tiers

> **Status:** Non-normative draft. The labels below are descriptive placeholders,
> not release or compliance gates.

These labels preserve the source taxonomy while leaving governance decisions
open. A repository can use different labels or define a complete promotion
policy in separately approved guidance.

## Experimental

Exploratory work intended for rapid learning. Interfaces, behavior, and
evaluation methods can change frequently, and the audience is deliberately
limited.

## Preview

A candidate capability exposed to a broader but still bounded audience for
feedback. The intended use is clearer than in Experimental, while compatibility
and support expectations can still evolve.

## Production

A capability intended for its documented supported use. This label alone does
not establish reliability, support, security, performance, or change-management
commitments.

## Undefined Governance

The items not yet defined are promotion gates, owners, evidence requirements,
and rollback criteria. The source also does not identify required tests, evaluation
thresholds, observability evidence, approval roles, support periods, or
demotion triggers. No tier becomes normative until those design inputs are
resolved explicitly.
